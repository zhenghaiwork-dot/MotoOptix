# MotoOptix Launch Checklist

The Astro site is complete as a verified pre-launch build. The following items require real business inputs and must not be invented in code.

## Ownership and identity

- [ ] Register and control the production domain
- [ ] Complete a trademark search for MotoOptix
- [ ] Insert the legal trading entity and registered address
- [ ] Replace legal-page placeholder notices after professional review
- [ ] Create production sales and privacy email addresses

## Product evidence

- [ ] Select one exact supplier model and revision for each public product
- [ ] Receive and identify the physical samples
- [ ] Complete `docs/SUPPLIER_INTAKE.md`
- [ ] Test critical recording, power and installation behavior
- [ ] Match available compliance documents to each selected configuration
- [ ] Obtain permission for all supplier product photography and documents
- [ ] Record MOQ, lead time, quotation validity, warranty and defect terms
- [ ] Advance `evidenceStage` only under `docs/PRODUCT_PUBLISHING_RULES.md`
- [ ] Add Product structured data only after a real product record exists

## Inquiry delivery

- [ ] Configure `PUBLIC_FORM_ENDPOINT`
- [ ] Configure `PUBLIC_RFQ_EMAIL`
- [ ] Test successful, invalid and spam submissions
- [ ] Confirm email authentication and delivery
- [ ] Define inquiry retention and deletion schedule
- [ ] Add a CRM only if actual workflow requires it

## Production SEO and operations

- [ ] Configure `SITE_URL` with the owned HTTPS domain
- [ ] Verify canonical URLs, `robots.txt` and sitemap on production
- [ ] Create Google Search Console and Bing Webmaster Tools properties
- [ ] Submit the production sitemap
- [ ] Add analytics only with the required privacy and consent controls
- [ ] Validate Organization, Article and FAQ structured data after deployment
- [ ] Check performance and accessibility on the production host
- [ ] Set redirects if the domain changes later

The unowned `dashcamsupply.com` must not appear in canonical tags, email addresses, legal text or structured data unless ownership is obtained.
