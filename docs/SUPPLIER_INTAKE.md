# MotoOptix Supplier Intake / 供应商资料采集表

This document is the source checklist for turning a 1688 listing into a publishable MotoOptix product. Do not copy marketplace claims directly into the website.

本文件用于把 1688 商品转化成可发布的 MotoOptix 产品资料。禁止未经核验直接复制平台宣传参数。

## 1. Product identity / 产品身份

| Required field | 供应商需提供 |
|---|---|
| Supplier company and contact | 公司名称、联系人 |
| Supplier model number | 工厂型号 |
| Hardware and firmware revision | 硬件版本、固件版本 |
| Mass-production status | 是否为稳定量产版本 |
| Standard configuration | 标配主机、镜头、线束、支架、配件 |
| Alternative configurations | 不同屏幕、镜头、GPS、TPMS 等选配 |
| Sample price and lead time | 样品价格与交期 |
| Standard MOQ and production lead time | 标准 MOQ 与大货交期 |

Every quotation, sample, report and website record must point to the same model and revision.

报价、样品、检测资料和网站记录必须对应同一型号与版本。

## 2. Camera and recording / 摄像与录像

- Sensor manufacturer and exact model / 传感器品牌与准确型号
- Native sensor resolution / 传感器原生分辨率
- Encoded file resolution / 文件输出分辨率
- Frame rate for each channel / 每路帧率
- Simultaneous front/rear behavior / 前后路同时录像状态
- Codec and approximate bitrate / 编码格式与码率
- Lens aperture and field of view / 光圈与视角
- WDR, HDR or EIS implementation / 宽动态、防抖实现方式
- Maximum supported storage / 最大存储容量
- File format, clip length and loop behavior / 文件格式、分段与循环录像
- Parking recording behavior / 停车监控逻辑

Required evidence: unedited original files from every channel and a photographed sample label.

必须取得：每路未经平台压缩的原始视频、样品铭牌照片。

## 3. Display and connectivity / 屏幕与连接

- Panel size, technology and native resolution / 屏幕尺寸、面板类型、原生分辨率
- Measured or supplier-declared brightness / 实测或供应商声明亮度
- Lamination and surface treatment / 贴合与表面处理
- CarPlay and Android Auto connection method / CarPlay 与 Android Auto 连接方式
- Bluetooth and Wi-Fi module identification / 蓝牙与 Wi-Fi 模块信息
- App name, owner, store links and privacy policy / App 名称、所有者、商店链接与隐私政策
- Supported phone and OS versions / 支持的手机与系统版本

Never publish “1000 nits,” “full lamination,” or app compatibility without matching evidence for the selected sample.

未获得对应样品证据前，不得发布“1000 nits”“全贴合”或 App 兼容性声明。

## 4. Electrical and environmental / 电气与环境

- Supported input-voltage range / 输入电压范围
- Normal, peak and standby consumption / 正常、峰值及待机功耗
- ACC detection and shutdown delay / ACC 检测与关机延时
- Low-voltage protection threshold / 低压保护阈值
- Battery or supercapacitor / 电池或超级电容
- Working and storage temperature / 工作与存储温度
- IP rating for display, recorder, cameras and connectors separately / 主机、镜头、接头分别的 IP 等级
- Vibration, drop, salt-spray or temperature reports if available / 振动、跌落、盐雾、温度报告
- Cable lengths, connector dimensions and fuse details / 线长、接头尺寸、保险丝信息

## 5. Private label / 轻定制

Record each item separately:

| Item | MOQ | Setup/NRE | Lead time | Evidence needed |
|---|---:|---:|---:|---|
| Boot logo / 开机 Logo | | | | Branded firmware sample |
| Product label / 产品标签 | | | | Artwork proof |
| Printed packaging / 彩盒 | | | | Dieline and proof |
| Manual or insert / 说明书、卡片 | | | | Approved PDF/source file |
| Housing mark / 外壳丝印 | | | | Physical pre-production sample |
| App branding / App 品牌化 | | | | Ownership and maintenance terms |

## 6. Compliance and commercial terms / 合规与商务

- CE, FCC, RoHS, UKCA or other available documents / 可提供的认证或报告
- Applicant, report number, model coverage and date / 申请人、报告号、覆盖型号与日期
- Radio-module coverage / 无线模块是否覆盖
- HS code and battery shipping documents / HS 编码及电池运输资料
- Warranty and DOA policy / 质保与到货损坏政策
- Spare-unit or spare-parts ratio / 备品比例
- Firmware-support period / 固件支持周期
- Defect evidence and RMA process / 不良证据与退换流程
- Carton dimensions, weight and quantity / 箱规、重量、装箱数
- Payment terms and Incoterm / 付款条款与贸易术语

## 7. Publication decision / 发布决定

A product may move through these stages:

1. `concept` — product family only; no fixed specification table
2. `sample-requested` — exact supplier revision selected
3. `sample-tested` — sample and critical claims reviewed
4. `commercially-approved` — MOQ, lead time, documents and support terms recorded

Only stages 3–4 may publish a fixed technical specification table. Only stage 4 may publish confirmed commercial terms.
